# Что в отзывах мешает продуктам одежды: мини-исследование для небольшого производства

Небольшому производству одежды трудно понять, куда вложить ограниченные ресурсы: менять ткань, пересматривать лекала, переписывать размерные таблицы? Этот проект отвечает на такие вопросы по 23 тысячам реальных отзывов покупателей (анонимизированные данные интернет-магазина женской одежды) и показывает метод, который можно повторить на собственных отзывах и возвратах.

## Главные выводы

1. **Причины недовольства лежат в ткани и крое, а не в размерах.** В 16% отзывов упомянута хотя бы одна «продуктовая» проблема (ткань и пошив, крой «не по фигуре», слишком короткое, «не как на фото»). Среди тех, кто не рекомендует товар, таких отзывов 43% против 11% среди рекомендующих: «не рекомендую» при такой жалобе встречается в 3,8 раза чаще (RR 3,80, 95% ДИ 3,61–3,99).
2. **Разговоры о размере почти не связаны с неудовлетворённостью.** Упоминание «маломерит» повышает вероятность «не рекомендую» лишь в 1,16 раза, «большемерит» не повышает вообще (RR 1,01). Покупатели часто просто советуют друг другу брать другой размер и остаются довольны. Размерная сетка важна, но это не главный рычаг.
3. **Разные классы изделий различаются слабо.** Значимо ниже остальных платья (80,8%, на 1,9 п.п.; именно здесь больше всего отзывов) и значимо выше джинсы (88,1%, на 6,2 п.п.). Класс «Trend» выглядит худшим (73,9%), но отзывов всего 119, и после поправки на множественные сравнения вывод неубедителен.
4. **Проблемы сидят в конкретных моделях.** Разброс удовлетворённости между 192 моделями (≥ 15 отзывов) намного превышает случайный шум (χ² = 498 при 191 степени свободы). Пять моделей с вероятностью выше 50% «проваливают» порог 75% рекомендаций. Лидирует модель ID 1087 (платье, 129 отзывов): 67% рекомендаций, жалобы на крой и ткань.
5. **Старшие покупатели довольнее.** Среди 60+ рекомендуют 85,2% против 81,2% у 40–49 лет. Эффект небольшой (V Крамера 0,037), но устойчивый (p < 0,001).

## Что из этого могло бы следовать для производства

Это гипотезы для проверки, а не доказанные причины: данные показывают связь, а не причинно-следственный эффект.

- Проверять ткань и качество пошива (усадка, сквозь просвечивает, ворсится, швы) на входном контроле: это самая частая из «продуктовых» жалоб.
- Пересматривать лекала у моделей из списка кандидатов (`results/tables/problem_items.csv`), а не менять всю линейку.
- Не ожидать от размерных таблиц чуда, но пометить тенденции: купальники и юбки чаще «маломерят» (18% и 13% упоминаний против 5% и 10% «большемерит»), а трикотаж, свитеры и шорты чаще «большемерят».
- В описании товара честнее показывать длину и посадку на разном росте: «слишком короткое» связано с неудовлетворённостью почти вдвое (RR 1,92).

## Как сделан анализ

1. **Чистка и проверки:** удалено 21 полное дублирование, отмечены противоречия (25 отзывов с рейтингом 5 и «не рекомендую», 16 с рейтингом 1 и «рекомендую»), отзывы без текста (825) исключены только из текстовой части.
2. **Темы в тексте** определяются словарём ключевых слов **с учётом отрицаний** («not at all itchy» не считается жалобой). Точность проверена вручную на случайных совпадениях: для ткани и качества 21 из 25 верно (84%), для кроя 15–18 из 25 (60–72%): слова вроде «boxy» бывают и нейтральными. Если ошибки разметки не зависят от оценки покупателя, они скорее занижают различия, чем создают их. Проверку можно повторить: `python scripts/sample_matches.py --theme shape_unflattering`.
3. **Классы изделий:** доля «рекомендую» с интервалом Уилсона, z-тест против остальных, поправка Холма.
4. **Темы и неудовлетворённость:** относительный риск с доверительным интервалом по log-RR, хи-квадрат, поправка Холма.
5. **Модели:** байесовское сжатие (Beta-приор по методу моментов), чтобы малые выборки не давали ложных «худших» моделей; тест на избыточный разброс; ранжирование по вероятности оказаться ниже заданного порога.
6. **Возраст:** хи-квадрат и V Крамера.

Полный автоматический отчёт с таблицами: [`results/report.md`](results/report.md). Данные для дальнейшей работы: `results/tables/*.csv`.

## Ограничения

- Данные одного магазина, женская одежда, в основном взрослая аудитория: выводы о рынке в целом делать нельзя.
- «Рекомендую / не рекомендую» — самооценка. Причина в тексте указана не всегда, а словарная разметка приблизительна.
- Нет данных о продажах, возвратах, цене и себестоимости, поэтому деньги не посчитаны. Для реального производства стоит сочетать отзывы с возвратами и выручкой.
- Возраст относится к автору отзыва, а не обязательно к тому, кто носит вещь.

## Запуск

```bash
python -m venv .venv && source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt

python scripts/download_data.py           # скачивает data/reviews.csv (или положите файл с Kaggle вручную)
python -m clothing_insights               # анализ -> results/
python -m clothing_insights --demo        # то же на синтетических данных, без скачивания
pytest -q                                 # тесты
```

Чтобы применить метод к своим отзывам, приведите файл к тем же колонкам (`Clothing ID`, `Age`, `Review Text`, `Rating`, `Recommended IND`, `Class Name` и т. д.) и словарь тем в `clothing_insights/themes.py` адаптируйте под свой язык и ассортимент.

## Структура

```
clothing_insights/
  data.py       загрузка, чистка, проверки, синтетические данные
  themes.py     словарная разметка тем с учётом отрицаний
  stats.py      Уилсон, RR, Холм, V Крамера, байесовское сжатие
  analysis.py   пять вопросов -> таблицы
  plots.py      графики
  report.py     запуск, report.md, CSV, summary.json
scripts/        download_data.py, sample_matches.py
tests/          pytest
results/        отчёт, таблицы и графики последнего запуска
```

## Данные

Women's E-Commerce Clothing Reviews (Kaggle, публикация Nick Brooks; по описанию набора — открытая лицензия CC0). Реальные коммерческие данные, анонимизированные: названия компании заменены на «retailer». Файл в репозитории не хранится.
